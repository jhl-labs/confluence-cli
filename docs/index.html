confluence-cli

셀프호스팅 Confluence Server/Data Center 환경에서 AI 에이전트와 자동화 스크립트가 문서를 읽고 쓰기 위한 가볍고 의존성 없는 CLI입니다. 단일 바이너리, 크로스플랫폼. A small, dependency-free CLI that lets AI agents and automation read and write pages on a self-hosted Confluence Server/Data Center instance. Single binary, cross-platform.

Go · 0 dependencies PAT / Basic auth JSON output Linux · macOS · Windows JHL License · non-commercial
$ curl -fsSL https://jhl-labs.github.io/confluence-cli/install.sh | sh
$ confluence-cli search --text "release notes" --output text

왜 필요한가Why

공식 Atlassian Remote MCP는 Cloud 전용입니다. The official Atlassian Remote MCP is Cloud-only.

Server/Data Center는 인증 방식·네트워크·권한 모델이 다릅니다. confluence-cli는 그 간극을 메우는 전용 CLI 계층으로, 인증(PAT/Basic), 재시도, CQL 검색, Confluence storage 포맷을 일관되게 처리해 에이전트가 안전하게 내부 위키를 다루게 합니다. Server/Data Center differs in auth, networking, and permission models. confluence-cli is a dedicated CLI layer that bridges the gap — handling auth (PAT/Basic), retries, CQL search, and the Confluence storage format so agents can work with internal wikis safely.

기능Features

에이전트 친화적으로 설계됨Designed for agents

검색 · 조회 · 작성Search · Read · Write

search / get / create / update / comment — 페이지 전 수명주기를 CLI로. search / get / create / update / comment — the full page lifecycle from the CLI.

Server/DC 인증Server/DC auth

Personal Access Token(Bearer) 우선, Basic 인증 폴백. Personal Access Token (Bearer) first, with Basic auth fallback.

JSON 우선 출력JSON-first output

기본은 파싱하기 좋은 JSON, --output text로 사람용 요약. JSON by default for easy parsing; --output text for humans.

견고한 호출Resilient calls

429/5xx에 지수 백오프 재시도, Retry-After 헤더 존중. Exponential-backoff retries on 429/5xx, honoring Retry-After.

에이전트 스킬 생성Agent skill generator

generate-skill로 claude/codex/gemini/opencode용 스킬 문서를 자동 생성. generate-skill emits skill docs for claude/codex/gemini/opencode.

storage 포맷 인지Storage-format aware

Confluence는 마크다운이 아님 — XHTML storage / wiki representation 지원. Confluence isn't Markdown — supports XHTML storage / wiki representations.

명령어Commands

환경변수로 인증을 분리Auth via environment

# 인증 환경변수Authentication
export CONFLUENCE_BASE_URL="https://confluence.example.com"
export CONFLUENCE_TOKEN="<personal-access-token>"
export CONFLUENCE_SPACE="DOCS"   # 기본 스페이스(선택)default space (optional)
searchCQL·텍스트로 페이지 검색find pages by text or CQL
confluence-cli search --text "release notes" --limit 10
confluence-cli search --cql 'type=page AND title ~ "design"'
getID로 페이지 조회read a page by ID
confluence-cli get --id 123456 --output text
confluence-cli get --id 123456 --body   # storage body
create새 페이지 생성create a page
confluence-cli create --space DOCS --title "New Page" --body "<p>Hello</p>"
echo "<p>Hi</p>" | confluence-cli create --title "Piped" --body-file -
update버전 자동 증가 수정edit (auto version bump)
confluence-cli update --id 123456 --body-file updated.xhtml
generate-skill에이전트용 스킬 문서 생성emit an agent skill doc
confluence-cli generate-skill claude    # or codex / gemini / opencode
confluence-cli generate-skill           # generic

주의Heads up

본문은 마크다운이 아닙니다Bodies are not Markdown

Confluence 본문은 XHTML 기반 storage 포맷입니다. create/update 시 기본은 storage이며, 위키 문법을 보내려면 --representation wiki를 쓰면 서버가 변환합니다. Confluence bodies use the XHTML storage format. create/update default to storage; pass --representation wiki to send wiki markup (converted server-side).
